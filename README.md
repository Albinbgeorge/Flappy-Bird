# 🐦 Flappy Bird Game (Python)

A simple Flappy Bird clone built using Python and Pygame.
This project demonstrates basic game development concepts such as physics, collision detection, sound effects, and scoring.

## 🎮 Features

* Gravity-based bird movement
* Space key jump control
* Random pipe generation
* Collision detection
* Score tracking
* Sound effects (flap, hit, die, point)
* Restart functionality
* Background and sprite support

## 🛠️ Built With

* Python
* Pygame

## ▶️ How to Run

1. Clone the repository

```
git clone https://github.com/your-username/Flappy-Bird.git
```

2. Navigate to project folder

```
cd Flappy-Bird
```

3. Install dependencies

```
pip install pygame
```

4. Run the game

```
python test.py
```

## 🎯 Controls

* SPACE → Jump
* SPACE (after game over) → Restart
* Close window → Exit

## 📸 Gameplay

Press space to start and avoid hitting the pipes.
Score increases each time you pass through a pipe.
